# Ustazon — нақты материалдардан Shorts жасау

Бұл бот мұғалімдерге арналған Ustazon материалдарын қазақша және орысша қысқа видеоға айналдырады. Бөлек логотип суреті қолданылмайды.

## Қазір дайын

- Екі расталған материал: 47632 карточкасы (8-сынып, зәр шығару жүйесі туралы презентация) және 47471 карточкасы (10-сынып, жеңілдетілген диффузия жұмыс парағы).
- 12 сценарий, әрқайсысы қазақша және орысша: барлығы 24 нұсқа. Видеода нақты слайд/диаграмма/карточка үзінділері көрсетіледі. Орысша дыбыстау бастапқы файлдың орысша нұсқасы бар дегенді білдірмейді.
- 1080×1920, 30 FPS, Gemini дауысы, субтитр, фондық музыка, PNG кадрлар, SRT және YouTube метадеректері.
- Күніне 10:00, 15:00, 20:00 (Asia/Qyzylorda): бір күні екі қазақша және бір орысша, келесі күні бір қазақша және екі орысша видео. Форматтар: сабаққа кеңес, материал таныстыру, шағын сұрақ.
- Өнім туралы деректер мен жарияланатын мәтін бекітілген сценариймен салыстырылады. Жоқ геометрия/салыстыру файлдары жарнамаланбайды.
- Сценарий қоры біткенде CONTENT_EXHAUSTED күйімен тоқтайды; ескі видеоны қайта жарияламайды. 12 тақырып × 2 тіл = 24 бөлек нұсқа. Тілдерді күн сайын алмастыру бұл қорды күніне үш видеодан 8 күнге бөледі; бұл екі материал шексіз жаңа тақырып бермейді.
- Үзілістен кейін бұрынғы тапсырма келесі күнге көшеді, кэштелген дыбыс сақталады. Ұзақ дыбыста бекітілген қысқа мәтін бір рет қолданылады.

## Жергілікті іске қосу

Node.js 24 немесе жаңарақ керек. FFmpeg пен Canvas тәуелділіктері төмендегі орнатумен келеді.

~~~sh
npm ci --prefix ustazon
npm run test:ustazon
npm run video:check
npm run video:budget
npm run video:daily
npm run video:status
~~~

Жоба түбіріндегі еленбейтін .env.local файлына GEMINI_API_KEY және тек Free Tier жобасы расталған жағдайда GEMINI_FREE_TIER_CONFIRMED=true қойыңыз. Кілтті GitHub кодына қоспаңыз.

video:daily жергілікті файл жасайды. video:worker тұрақты жұмыс істейді; video:stop оны тоқтатады. generate --only morning|afternoon|evening бір слотты жалғастырады. node ustazon/review.mjs соңғы үш дайын видеоны ustazon/review ішіне жинайды.

automation.json ішіндегі languageRotation 2026-11-15 күнінен бастап тілдерді алмастырады: бастапқы күні KK/KK/RU, келесі күні RU/RU/KK. Бұрын жоспарланған күннің тілдері мен YouTube уақыты өзгермейді. Аяқталмаған видео өз тілін, дыбыс кэшін және жүктеу тарихын сақтайды. Әр тақырып әр тілде бір рет қана таңдалады; орысша нұсқада дауыс, субтитр және метадеректер орысша болады. Генерация лимитіне байланысты күндік үш роликке кепіл жоқ.

## Тегін Gemini шегі

Өндірістік content.mode=verified: сценарий үшін API шақырылмайды. Үш видеода 9 жаңа дауыс сұрауы керек; аяқтау сөйлемдерінің екі дайын дыбысы assets/narration ішінде сақталған. Сәтсіз әрекеттер де саналады. Қазіргі шектер: мәтінге 6, дауысқа 10, барлығына 16 сұрау; бір модельге сұрау арасы 61 секунд.

Бұл сандар пайдаланушы берген 2026-11-14 Free Tier скриншотына негізделген. Басқа қолданбалар сол жобаның квотасын бөліседі. Ақылы billing қосылған жобаға жергілікті санағыш тегіндік бермейді. Нақты бүгінгі қалған квота скриншоттағы 28 күндік peak көрсеткішінен анықталмайды.

Уақытша байланыс үзілсе, жартылай дайын видео сақталады. Квота біткенде бот келесі Pacific reset уақытын күтеді; есептегішті өшіру арқылы лимит айналып өтілмейді. Қалыпты күнгі 9 сұраудың үстіне бір қайта дыбыстауға орын қалады, сондықтан үш роликке күн сайын кепіл жоқ.

## GitHub Actions

.github/workflows/ustazon-checks.yml код пен барлық 24 макетті тексереді. .github/workflows/ustazon-shorts.yml генерация мен жариялауды орындайды. Автоматты кесте USTAZON_AUTOMATION_ENABLED=true болғанда ғана қосылады.

Gemini кілті мен шифрланған тарихты тексеру үшін Actions → Ustazon Shorts → Run workflow ішінде check_only=true, initialize=false таңдаңыз. Бұл режим модельдерге қолжетімділікті, сақталған лимит есебін және дайын видеоларды тексереді; жаңа дыбыс не видео жасамайды және YouTube-ке жарияламайды. Тарихты алдын ала көшіру керек. Тексеріс нәтижесіндегі ustazon-review артефактісінен бұрын дайындалған видеоларды алуға болады.

Repository Settings → Secrets and variables → Actions:

| Түрі | Атауы | Мәні |
|---|---|---|
| Secret | GEMINI_API_KEY | Gemini жобасының API кілті |
| Secret | USTAZON_STATE_KEY | Кездейсоқ 32 байттың base64 жолы; бір рет жасалып, сақталады |
| Variable | GEMINI_FREE_TIER_CONFIRMED | Тегін жоба расталғанда true |
| Variable | USTAZON_AUTOMATION_ENABLED | Алғашқы қолмен іске қосу тексерілгеннен кейін true |
| Variable | USTAZON_PUBLISH_ENABLED | Арна қосылмағанша false |

Күй кілтін жергілікті Node арқылы жасауға болады: node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))". Оны тек Secret ретінде және өзіңіз сақтайтын қауіпсіз орынға жазыңыз. Кейін бұл кілтті ауыстырмаңыз: бұрынғы күйді оқу үшін сол кілт керек.

Жаңа, тарихы жоқ орнатуда: Actions → Ustazon Shorts → Run workflow → initialize=true. Кейінгі барлық іске қосуда initialize=false. Қазір жергілікті жасалған видеоларды/есептегіштерді жалғастыру үшін бос тарих ашпай, алдымен төмендегі көшіру тәсілін қолданыңыз.

Runtime күйі репозиторийдегі арнайы ustazon-runtime-state-v1 Release ішінде AES-256-GCM арқылы шифрланып сақталады. GitHub токеніне contents:write қажет. SQLite-тің онлайн көшірмесі, есептегіштер, аяқталмаған жүктеу сессиялары, дыбыс кэші мен жарияланбаған видеолар әр маңызды save кезінде жіберіледі. API сұрауы санағыштың қашықтағы көшірмесі расталғаннан кейін ғана жүреді. Соңғы екі толық көшірме сақталады; бөтен Release файлдары өшірілмейді.

Жаңа runner ең соңғы көшірмені қалпына келтіреді. Соңғы көшірме бүлінсе, үнсіз ескі тарихпен жұмыс бастамайды. Release не күй кілті жоғалса, дұрыс көшірмені қалпына келтіру қажет. Бір репозиторийге тек осы concurrency тобындағы workflow жұмыс істеуі керек; жергілікті worker-ді қатар іске қоспаңыз.

Кесте UTC 23:17, 04:17, 09:17, 14:17 уақыттарында іске қосылады: Қазақстандағы слоттарға алдын ала дайындайды. GitHub кестесі дәл минутта іске қосылуға кепіл бермейді. Дайын видеолар шифрланған runtime күйінде қалады; соңғы үш видео қосымша review artifact ретінде 3 күн беріледі.

## Осы компьютердегі күйді Actions-қа көшіру

Жергілікті worker тоқтаған кезде GITHUB_REPOSITORY=galymzhan120202-cyber/Dara-Teacher, GITHUB_TOKEN (репозиторийдің Contents write рұқсатымен) және USTAZON_STATE_KEY орта айнымалыларын орнатыңыз. Күй кілті Actions Secret-тегі мәнмен бірдей болуы керек. Содан кейін node ustazon/seed-state.mjs командасын орындаңыз. Ол жергілікті SQLite тарихын, бүгін жұмсалған квотаны және сақталған дыбысты шифрлап көшіреді; Git репозиторий кодына жазбайды. Қашықта бұрыннан тарих болса, оны басып жазудан бас тартады. Көшіру расталған соң Actions-ты initialize=false параметрімен іске қосыңыз.

## YouTube қосу

1. Google Cloud-та YouTube Data API қосып, Desktop OAuth client файлын жоба түбіріне client_secrets.json ретінде сақтаңыз.
2. automation.json ішіндегі expectedChannelId өрісін немесе YOUTUBE_CHANNEL_ID айнымалысын арна ID-іне қойыңыз.
3. npm run video:youtube:connect арқылы жергілікті браузерде сол арнаға кіріңіз. Арнаны оқу және видео жүктеу рұқсаттарының екеуін де беріңіз. Бот арна ID-ін салыстырады. node ustazon/daily.mjs youtube-check рұқсатты жаңартып, арнаны тексереді; видео жүктемейді.
4. Actions-та YOUTUBE_CLIENT_JSON_B64 және YOUTUBE_TOKEN_JSON_B64 Secrets мәндеріне client_secrets.json және ustazon/.state/youtube-token.json файлдарының base64 нұсқаларын қосыңыз. YOUTUBE_CHANNEL_ID Variable мәнін орнатыңыз.
5. Бір сынақ жүктеуі тексерілгеннен кейін USTAZON_PUBLISH_ENABLED=true қойыңыз.

OAuth файлдары кодпен бірге жарияланбайды. Қалпына келтірілген жаңа токен болса, workflow оны ескі Secret нұсқасымен алмастырмайды. Жүктеудің соңғы жауабы жоғалса, сол сессия тексеріледі; екінші видео автоматты ашылмайды.

YOUTUBE_CHANNEL_ID орнатылған кезде Actions-тағы check_only режимі YouTube рұқсатын жаңартуды және арна ID-ін де тексереді. Google Auth қолданбасы External / Testing күйінде болса, YouTube refresh token 7 күннен кейін жарамсыз болады. Ұзақ мерзімді жұмыс үшін Google Auth Platform-дағы Production талаптарын аяқтап, арнаны қайта қосыңыз.

## Контентті кеңейту

2026-11-20 hook редакциясы: 12 сценарийдің екі тілдегі алғашқы көрінісі қысқа сұрақпен, бақылау тапсырмасымен немесе мұғалімге нақты әрекет ұсынумен басталады. Экрандағы тақырып пен дыбыстаудың басталуы бір ойды береді; келесі көріністер сұрақты материалмен түсіндіреді. Қысқартылған дыбыстау да hook-ты сақтайды. Hook мәтіні мен материалы бірінші кадрдан толық айқындықпен көрсетіледі; басқа көріністердің ауысу анимациясы сақталған.

Өндірісте `content.mode=verified` болғандықтан негізгі мәтін `stories.json` файлынан келеді. Жаңа сценарийде алғашқы сөйлемді қысқа ұстаңыз, ұзақ сәлемдесу мен бренд таныстырудан бастамаңыз, дәлелсіз уәде қоспаңыз. Балама AI сценарий режимінің нұсқаулығында да осы талаптар бар. Мәтін мен кадрды тексеру көрерменнің видеоны соңына дейін көруіне кепіл бермейді; оны жарияланғаннан кейінгі статистикамен бағалау керек.

stories.json — негізгі сценарий қоры. Әр story үшін тұрақты id, material, format, екі тілдегі тақырып/сипаттама және үш scene берілген. Оларды өзгерткенде npm run video:catalog-sync арқылы catalog.json-ды жаңартыңыз. assets/materials/manifest.json кескіннің SHA-256 сомасын, карточкасын және бастапқы үзіндіні сақтайды. Жаңа материал қоспас бұрын оның нақты файлын не үзіндісін тексеріңіз.

Сценарий өзгергенде бұрын дайындалған, әлі жүктелмеген видео жаңа мәтінмен қайта жасалады. Жүктелген роликтердің тарихы сақталады. Қор біткен тапсырманы жаңа материал қосқаннан кейін node ustazon/daily.mjs retry --job JOB_ID арқылы кезекке қайтаруға болады.

Субтитр уақыттары дыбыстың жалпы ұзақтығына қарай жуық есептеледі; сөз деңгейіндегі сәйкестікке кепіл жоқ. Жазылған сценарий мен файлдың дұрыстығын автоматты тексеру диктордың табиғи айтылуын немесе көрермен қызығушылығын өлшемейді. Алғашқы жарияланымдарды тыңдап, көріп тексеріңіз.
