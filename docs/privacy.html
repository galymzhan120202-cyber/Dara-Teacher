Who operates the app

DaraTeacher is operated by the owner of the DaraUstaz channel to prepare and publish videos about Ustazon educational materials. It is an owner-operated tool, not a public service for connecting other people's channels. Contact: ustazonyt@gmail.com.

Google and YouTube data

The app uses YouTube API Services. With the account owner's Google OAuth consent, it requests:

  • youtube.readonly to read the authorized channel's identifier and title and verify that the intended channel is connected.
  • youtube.upload to upload video files, titles, descriptions, language information and publication settings selected by the operator.

The app stores OAuth access and refresh tokens, the connected channel identifier, and upload records such as video identifiers, upload progress and publication status. These records allow authorization to be refreshed and interrupted uploads to resume without intentionally creating duplicate videos. The app does not ask for or store the user's Google password.

How data is used and shared

Google authorization data is used for the connected YouTube channel and the app's upload workflow. Tokens and upload requests are sent to Google's OAuth and YouTube API endpoints. Videos become visible according to their YouTube privacy and scheduled publication settings.

When the bot runs on GitHub Actions, GitHub processes the workflow and stores repository secrets and encrypted runtime backups. Credentials are excluded from the public source code. Local authorized copies may remain on the operator's computer. YouTube account data is not sold, used for advertising, or sent by this app to an AI model.

The video-generation process can send educational narration text supplied or approved by the operator to the Gemini API for speech generation. This is separate from Google OAuth and YouTube account data. Google processes these requests under the terms applicable to the operator's Gemini project.

Storage and retention

Authorization files are kept while the connection is in use. In GitHub, the initial credentials are stored as Actions Secrets and runtime backups are encrypted. Publication receipts are retained to track work and prevent duplicate uploads. Media caches, logs and backups follow the bot's configured retention rules. Revoking access prevents further authorized API access but does not by itself erase local files, GitHub secrets, backups or videos already uploaded to YouTube.

Revoke access or request deletion

The account owner can revoke the app's Google access through Google Account permissions. To remove saved authorization and associated bot records, contact ustazonyt@gmail.com. The operator can stop the workflow and remove the local authorization files, repository secrets and relevant stored backups. Existing YouTube videos are managed separately in YouTube Studio.

This website

This static information site has no sign-in form, analytics scripts, advertising scripts or app cookies. GitHub Pages hosts the site and logs visitor IP addresses for security according to the GitHub Privacy Statement.
